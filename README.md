# TechToss-Application
Authors: Alexander Liu / Julian Kroeger-Miller
## Functionality
Document and tabulate information regarding the current inventory of Techtoss electronics/projects and the details regarding donations/transactions with clients. 

Current objectives
- establish an Inventory application
- establish a Donation/Transaction application
- establish a TechToss portal

### Reminder
We need to establish proper security measures for these applications, such as user accounts and passwords.

## Inventory
The inventory should encompass the details pertaining to specific items and items that we have in bulk, with their locations, status, and any important details (e.g., operating system, ram, manufacturer, etc.)
This could be simplified with the use of Excel, but it would be ideal if we had a method of documentation that's easier for any user to access and filter through for items.

## Donations & Transactions

We need to track the items we donate and sell to clients since we need to track $ money donated via electronic items.
I'm thinking of using an API to do quick cost analysis of items that are sold. Might be a little confusing, but it could be an approach.
